========================================================================
                          HƯỚNG DẪN SỬ DỤNG TBCO (v3.0 PRO)
========================================================================

TBCO là ứng dụng dịch thuật hội thoại game thời gian thực (hỗ trợ tối ưu cho 
Fate/Grand Order, Visual Novel, RPG giả tưởng và Anime) sử dụng công nghệ 
Windows WinRT OCR và trí tuệ nhân tạo Google Gemini 3.x (kế thừa MORT).

------------------------------------------------------------------------
1. BẮT ĐẦU SỬ DỤNG (KHÔNG CẦN CÀI ĐẶT .NET)
------------------------------------------------------------------------
- Ứng dụng đã được đóng gói độc lập (Self-Contained). Bạn chỉ cần:
  1. Giải nén toàn bộ file trong file zip vào một thư mục (ví dụ: D:\TBCO).
  2. Nhấp đúp vào file "TBCO.exe" để mở ứng dụng.

* LƯU Ý BẢO MẬT TRÊN WINDOWS 10 / 11 (SMARTSCREEN & SMART APP CONTROL):
  1. Mở khóa file zip: Trước khi giải nén, nhấp chuột phải vào file zip -> Properties -> 
     Tích vào ô "Unblock" (Bỏ chặn) ở góc dưới -> Bấm OK.
  2. Cảnh báo xanh "Windows protected your PC":
     -> Bấm vào dòng chữ "More info" (Xem thêm thông tin)
     -> Chọn "Run anyway" (Vẫn chạy).
  3. Smart App Control (Windows 11): Ứng dụng dùng runtime chuẩn Microsoft.
     Nếu máy bạn bật SAC ở chế độ Enforce nghiêm ngặt, hãy đặt về 'Evaluation' hoặc 'Off' 
     trong Windows Security -> App & browser control -> Smart App Control settings.

------------------------------------------------------------------------
2. CẤU HÌNH BỘ DỊCH THUẬT (GEMINI / DEEPL / GOOGLE WEB)
------------------------------------------------------------------------
TBCO hỗ trợ linh hoạt 3 nhà cung cấp dịch thuật hàng đầu:

A. GOOGLE GEMINI 3.X AI (MẶC ĐỊNH - KHUYÊN DÙNG):
   - Vào Tab [Cài đặt & API] -> Chọn Nhà cung cấp: "Google Gemini AI".
   - Dán API Key Gemini của bạn và bấm [Lưu Key].
   - Hỗ trợ các model AI tiên tiến nhất: gemini-3.5-flash, gemini-3.6-flash, gemini-3.1-pro...
   - Lấy API Key miễn phí tại: https://aistudio.google.com/

B. DEEPL TRANSLATE (DỊCH CHUẨN XÁC, VĂN PHONG TỰ NHIÊN):
   - Vào Tab [Cài đặt & API] -> Chọn Nhà cung cấp: "DeepL Translate".
   - Dán DeepL Authentication Key của bạn và bấm [Lưu Key].
   - Tự động nhận diện cả gói DeepL Free (đuôi :fx) và gói DeepL Pro.
   - Lấy Auth Key tại: https://www.deepl.com/your-account/keys

C. GOOGLE WEB TRANSLATE (MIỄN PHÍ 100% - KHÔNG CẦN KEY):
   - Chọn "Google Web Translate" trong danh sách Nhà cung cấp.
   - Bạn có thể bắt đầu dịch ngay lập tức mà không cần tạo hay điền bất kỳ API key nào!

------------------------------------------------------------------------
3. CÁCH SỬ DỤNG KHI CHƠI GAME
------------------------------------------------------------------------
1. Mở game hoặc trình giả lập (VD: LDPlayer, MuMu, Nox, BlueStacks hoặc game PC).
2. Bấm nút [Đổi cửa sổ] để chọn đúng cửa sổ game của bạn.
3. Bấm [Quét vùng mới] để kéo chuột khoanh vùng hiển thị phụ đề/hội thoại của game.
4. Bấm [BẮT ĐẦU DỊCH] (hoặc bấm F6).
5. Bấm [Tách cửa sổ] (hoặc bấm F11) để bung ra một Cửa sổ phụ đề nổi độc lập trên màn hình game!

------------------------------------------------------------------------
4. BẢNG PHÍM TẮT & CÁC TÍNH NĂNG TIỆN ÍCH CAO CẤP
------------------------------------------------------------------------
Bấm [F1] hoặc click vào nút [⌨ Phím tắt] trên cửa sổ phụ đề để mở Bảng tra cứu phím:

* NHÓM QUÉT & BẮT HÌNH:
  - F6:      Bật / Tắt chế độ dịch tự động liên tục (Hook loop).
  - F7:      Chụp và dịch ngay 1 khung hình đơn lẻ.
  - F8:      Chụp nhanh lưu ảnh & dịch tức thì (Snapshot).
  - Ctrl+F8: Kéo chuột chọn vùng quét OCR mới trên màn hình.

* NHÓM PHỤ ĐỀ & HIỂN THỊ:
  - F9:      Khóa / Mở khóa xuyên chuột phụ đề (Click-Through) để thao tác game.
  - F10:     Ẩn / Hiện thanh phụ đề nổi (Overlay HUD).
  - F11:     Tách rời / Gắn lại cửa sổ phụ đề độc lập.
  - A- / A+: Tăng / giảm cỡ chữ tức thì trên cửa sổ phụ đề nổi.

* NHÓM DỊCH THUẬT & HỆ THỐNG:
  - Ctrl+T:  Dịch lại câu thoại gần nhất.
  - Ctrl+L:  Bật / Tắt chế độ Local AI (Ollama) ngoại tuyến.
  - Ctrl+K:  Mở hộp thoại quản lý API Key Pool.
  - F1:      Mở Bảng tra cứu phím tắt (Hotkey Cheatsheet).

------------------------------------------------------------------------
5. TÙY BIẾN THUẬT NGỮ & NHÂN VẬT
------------------------------------------------------------------------
- characters.json: Chứa danh sách nhân vật, cách xưng hô, văn phong dịch riêng biệt.
- glossary.json: Chứa bảng tra cứu thuật ngữ chuyên ngành game (Noble Phantasm, Servant,
  Singularities, Chén Thánh, Bảo Khí...).
Bạn có thể mở 2 file này bằng Notepad để bổ sung thêm bất kỳ từ nào bạn muốn!

Chúc bạn có những giây phút trải nghiệm game tuyệt vời cùng TBCO!
